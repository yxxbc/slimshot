# 选区操作 UI 与插件位

> 涉及：`src/bridge/overlay_view.m`、`overlay_action_rail.m`、`thumbnail.m`
> 改选区操作条、插件按钮或快捷键前先读这份。

## 调研：开源截图工具怎么做

| 工具 | 选区/操作 UI 的可借鉴点 |
| --- | --- |
| [capcap](https://github.com/realskyrin/capcap) | 选区右侧一条**垂直操作轨**（复制/保存/上传/固定/OCR/取消/确认），底部另一条横向工具栏放标注工具；左上角显示尺寸；确认/取消在轨道底部，颜色区分 |
| [macshot](https://github.com/sw33tLie/macshot) | 右侧垂直轨放输出/OCR/保存/上传等动作，底部横向工具栏放箭头/文字/形状；图标多、固定宽度、tooltip；OCR 有独立快捷键 |
| [Snapzy](https://github.com/duongductrong/Snapzy) | 截图后出现 Quick Access 浮动卡（复制/编辑/拖动/打开/删除）；每种截图模式可配置动作矩阵；快捷键可自定义 |
| [PinboardShot](https://github.com/agent-club/PinboardShot) | 选区边缘可调，双击直接复制，工具栏放标注/复制/固定；快捷键可配置 |
| [Flameshot](https://github.com/flameshot-org/flameshot) | 侧边栏用 Space 显隐，动作大量依赖快捷键；工具和输出动作分开 |
| [Shottr](https://shottr.cc/)（闭源，参考 UI） | 工具多时优先横向工具栏，窗口足够大就全部显示；OCR 走独立快捷键 |
| [Ksnip](https://github.com/ksnip/ksnip) | 截图后进入带标签页的编辑器；OCR 是独立插件；输出动作与编辑动作分离 |
| [Greenshot](https://github.com/greenshot/greenshot) | 截图后进入编辑器，插件/外部命令出现在编辑器动作里 |

## 结论

1. **输出/插件动作和标注工具分开**。动作放垂直轨，标注工具放底部横向栏。
2. 垂直轨是固定宽度，**天然能放很多图标**；横向栏会随插件数量变长，容易超出屏幕。
3. 图标优先，文字放 tooltip；主操作（确认/取消）固定在最下方并用颜色区分。
4. 尺寸信息放在选区旁边的小胶囊里，不占操作栏。
5. 必须有**溢出**：超过槽位用「…」菜单，不能把按钮挤出屏幕。
6. 高频动作配键盘快捷键。

## Slimshot 的实现

### 垂直操作轨

- 宽度 44pt，每行 34pt，圆角深色背景。
- 插件槽位：最多 4 个图标直接显示；更多时第 5 个是「…」菜单。
- 分隔线下面是蓝色 ✓ 截图和灰色 × 取消。
- 图标来自 manifest 的 `icon`（SF Symbol）；缺失时用 `puzzlepiece.extension`。
- 每个按钮有 tooltip：插件名 + 数字快捷键。
- 数字键 `1`–`9` 直接运行对应插件；`Return` 截图，`Esc` 取消。
- 位置优先级：选区右侧 → 选区左侧 → 选区内部右侧；顶部对齐，避开刘海/菜单栏，超出屏幕时上移。
- 点击轨道空白区域不会穿透到选区。

### 尺寸胶囊

- 选区左上角外侧显示 `宽 × 高 (x, y)` 和像素尺寸；上方没空间时放到选区下方。
- 不再把尺寸文本塞进操作栏，因此操作栏可以保持窄。

### 缩略图

- 全屏/窗口截图后的浮动缩略图底部也放插件图标。
- 最多 4 个 + 「…」溢出菜单；tooltip 显示名称。
- 有插件时缩略图至少停留 8 秒。

### 其他入口

- 菜单栏「插件」仍是完整列表（带图标），适合低频或不常用插件。
- 设置 →「插件」显示目录和已安装列表。

## 后续

- 设置里允许选择哪些插件进入快速轨、排序、启用/禁用。
- 每个插件自己的设置 UI（例如 OCR 语言）。
- 如果加入内置标注工具，按调研结论放到底部横向栏，不要继续塞进垂直轨。
- Quick Access 式截图后浮动卡可独立于缩略图演进。
